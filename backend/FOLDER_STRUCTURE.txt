DATABASE MODELS (8 Models)
===========================

1. User              - Base authentication model
2. Intern            - Intern profiles and details
3. Mentor            - Mentor profiles and expertise
4. Department        - Organizational departments
5. Task              - Task management and tracking
6. Feedback          - Performance feedback system
7. Announcement      - System announcements
8. Attendance        - Daily attendance tracking


API ENDPOINTS (7 Endpoints)
============================

Authentication:
├── POST   /api/v1/auth/register         # Register new user
├── POST   /api/v1/auth/login            # Login user
├── POST   /api/v1/auth/logout           # Logout user
├── POST   /api/v1/auth/refresh-token    # Refresh access token
├── POST   /api/v1/auth/forgot-password  # Request password reset
├── POST   /api/v1/auth/reset-password   # Reset password
└── GET    /api/v1/auth/me               # Get current user

Utility:
└── GET    /api/v1/health                # Health check

QUICK START COMMANDS
====================

# Install dependencies
npm install

# Setup database
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed

# Start development server
npm run dev

# Open database GUI
npm run prisma:studio

# Build for production
npm run build

# Start production server
npm start
